Developer Documentation

Full Stack Architecture & Setup Guide

1. Project Structure (Next.js 14 App Router)

pulse-app/
├── app/
│   ├── (auth)/login/page.tsx
│   ├── discover/page.tsx
│   ├── place/[id]/page.tsx
│   ├── api/vibe-engine/route.ts
│   └── page.tsx (Landing)
├── lib/
│   ├── vibe-engine.ts
│   └── supabase-client.ts
└── components/
    ├── VibeTimelineChart.tsx
    └── InteractiveMap.tsx

2. Supabase PostgreSQL Schema SQL

CREATE TABLE users ( id UUID PRIMARY KEY, username TEXT, xp_points INT DEFAULT 0, current_level INT DEFAULT 1 );
CREATE TABLE places ( id UUID PRIMARY KEY, name TEXT, category TEXT, lat FLOAT, lng FLOAT );
CREATE TABLE vibe_checkins ( id UUID PRIMARY KEY, place_id UUID REFERENCES places(id), vibe_type TEXT, noise_level INT, created_at TIMESTAMPTZ DEFAULT NOW() );
